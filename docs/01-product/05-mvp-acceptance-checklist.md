# 05 一期市场 MVP 验收清单

> 当前有效性：本文档是一期市场发行版的产品验收口径。旧 `docs/09-acceptance-checklist.md` 中与本 MVP 不一致的机构、写手、OnlyOffice、复杂阶段流转验收项，不作为一期发行阻塞项。

## 1. 用户注册登录

| 验收项 | 操作步骤 | 预期结果 | 是否必须通过 | 风险等级 | 备注 |
|---|---|---|---|---|---|
| 注册可用 | 游客进入注册页，提交合法账号信息。 | 注册成功并进入登录态或引导登录。 | 是 | P0 | 不要求多种注册方式都完成，但至少一种可用。 |
| 登录可用 | 使用已注册账号登录。 | 登录成功，可进入个人中心和生成入口。 | 是 | P0 | 登录失败需有明确错误提示。 |
| 登录态保护 | 未登录访问个人中心、生成、我的论文等页面。 | 跳转登录或提示需登录。 | 是 | P0 | 防止未登录生成或访问他人资产。 |
| 退出登录 | 已登录用户点击退出。 | 清除登录态，受保护页面不可继续访问。 | 是 | P1 | 影响账户安全。 |

## 2. 充值支付

| 验收项 | 操作步骤 | 预期结果 | 是否必须通过 | 风险等级 | 备注 |
|---|---|---|---|---|---|
| 创建充值订单 | 额度不足用户点击充值并选择套餐。 | 生成待支付订单，金额、套餐、订单号正确。 | 是 | P0 | 金额展示必须与实际支付一致。 |
| 支付成功到账 | 完成支付或测试支付成功流程。 | 订单变为已支付，额度增加。 | 是 | P0 | 额度到账是商业闭环核心。 |
| 支付失败/取消 | 支付失败或取消支付。 | 订单保持待支付/失败/关闭状态，不增加额度。 | 是 | P0 | 防止未支付到账。 |
| 重复回调/重复确认 | 对同一订单重复触发支付成功确认。 | 不重复增加额度。 | 是 | P0 | 支付幂等必须通过。 |

## 3. 订单状态

| 验收项 | 操作步骤 | 预期结果 | 是否必须通过 | 风险等级 | 备注 |
|---|---|---|---|---|---|
| 订单列表展示 | 用户进入个人中心订单列表。 | 可看到待支付、已支付、失败/关闭等状态。 | 是 | P0 | 状态文案要面向用户可理解。 |
| 订单详情 | 点击订单详情。 | 展示金额、状态、创建时间、支付时间或失败原因。 | 是 | P1 | 便于售后排查。 |
| 状态刷新 | 支付后返回或刷新订单页。 | 状态能更新为已支付或提示仍待确认。 | 是 | P0 | 避免用户付费后无法继续生成。 |

## 4. 额度扣减

| 验收项 | 操作步骤 | 预期结果 | 是否必须通过 | 风险等级 | 备注 |
|---|---|---|---|---|---|
| 生成前余额检查 | 额度不足时点击生成。 | 阻止生成并引导充值。 | 是 | P0 | 防止负额度或无权益生成。 |
| 生成成功扣减 | 额度充足并成功生成。 | 按规则扣减额度，并记录扣减流水。 | 是 | P0 | 扣减规则必须清晰。 |
| 生成失败不误扣 | 模拟生成失败。 | 不扣额度，或已扣额度可自动/人工补偿且有记录。 | 是 | P0 | 信任风险最高。 |
| 重复提交防护 | 快速多次点击生成。 | 不重复创建扣费或重复扣减。 | 是 | P0 | 防止多扣。 |

## 5. AI 生成

| 验收项 | 操作步骤 | 预期结果 | 是否必须通过 | 风险等级 | 备注 |
|---|---|---|---|---|---|
| 输入论文要求 | 填写题目/方向/专业/字数/要求等字段。 | 必填校验清晰，提交参数可用于生成。 | 是 | P0 | 字段可轻量，不追求全量学术数据。 |
| 选择生成类型 | 选择一期支持的生成类型。 | 生成类型被正确记录并影响生成结果。 | 是 | P0 | 无效类型不可提交。 |
| 生成中状态 | 点击生成后等待。 | 页面展示 loading/生成中，避免用户重复误操作。 | 是 | P0 | 长耗时任务必须有反馈。 |
| 生成成功 | 等待生成完成。 | 展示生成内容，并可保存或自动保存。 | 是 | P0 | 内容需可读、可复制/编辑。 |
| 生成失败 | 模拟模型/API/网络失败。 | 展示失败原因、重试或人工处理入口，额度处理正确。 | 是 | P0 | 发行前必须验证。 |

## 6. 内容保存

| 验收项 | 操作步骤 | 预期结果 | 是否必须通过 | 风险等级 | 备注 |
|---|---|---|---|---|---|
| 生成结果保存 | 生成成功后保存结果。 | 内容进入我的论文/我的任务。 | 是 | P0 | 不能只存在当前页面。 |
| 刷新恢复 | 保存后刷新页面或重新进入。 | 内容仍可查看。 | 是 | P0 | 防止用户资产丢失。 |
| 权限隔离 | 用户 A 尝试访问用户 B 的内容。 | 无法访问。 | 是 | P0 | 数据安全底线。 |

## 7. 合稿编辑

| 验收项 | 操作步骤 | 预期结果 | 是否必须通过 | 风险等级 | 备注 |
|---|---|---|---|---|---|
| 进入合稿页 | 从我的论文/任务进入合稿与格式调整。 | 可看到已保存内容。 | 是 | P0 | 一期可轻量。 |
| 编辑保存 | 修改标题、章节或正文后保存。 | 保存成功，刷新后不丢失。 | 是 | P0 | 不要求复杂协同。 |
| 空内容处理 | 无生成内容时进入。 | 展示 empty 状态并引导先生成。 | 是 | P1 | 降低用户困惑。 |
| 保存失败处理 | 模拟保存失败。 | 提示失败且不覆盖本地未提交内容。 | 是 | P1 | 防止内容损失。 |

## 8. Word 导出

| 验收项 | 操作步骤 | 预期结果 | 是否必须通过 | 风险等级 | 备注 |
|---|---|---|---|---|---|
| 导出 DOCX/Word | 在已保存内容上点击导出。 | 生成可下载 DOCX/Word 文件。 | 是 | P0 | 一期核心交付物。 |
| 下载文件可打开 | 下载文件后用 Word/WPS/兼容工具打开。 | 文件可打开，主体内容完整。 | 是 | P0 | 不要求复杂学校模板。 |
| 导出失败处理 | 模拟导出失败。 | 展示失败原因或重试入口。 | 是 | P1 | 避免用户无反馈。 |
| 导出记录 | 导出成功后返回我的论文/任务。 | 可看到导出记录或下载入口。 | 是 | P1 | 便于重复下载。 |

## 9. 人工服务申请

| 验收项 | 操作步骤 | 预期结果 | 是否必须通过 | 风险等级 | 备注 |
|---|---|---|---|---|---|
| 提交申请 | 用户从论文/任务中提交人工服务需求。 | 申请创建成功，状态为待处理。 | 是 | P0 | 可引用已生成内容。 |
| 申请字段校验 | 缺少联系方式或需求描述时提交。 | 阻止提交并提示。 | 是 | P1 | 字段保持最小可用。 |
| 查看申请状态 | 用户进入服务申请记录。 | 可看到待处理/处理中/已完成等状态。 | 是 | P0 | 只需状态，不做复杂工单。 |

## 10. 后台处理

| 验收项 | 操作步骤 | 预期结果 | 是否必须通过 | 风险等级 | 备注 |
|---|---|---|---|---|---|
| 查看服务申请 | 管理员进入后台服务申请列表。 | 可看到用户提交的待处理申请。 | 是 | P0 | 人工服务兜底入口。 |
| 更新处理状态 | 后台将申请从待处理更新为处理中/已完成。 | 用户侧状态同步更新。 | 是 | P0 | 不要求复杂派单。 |
| 查看订单/额度异常 | 管理员查看用户订单和额度。 | 可定位支付到账和扣减问题。 | 是 | P0 | 发行兜底能力。 |
| 后台权限 | 普通用户访问后台。 | 被拒绝或跳转。 | 是 | P0 | 基础安全要求。 |

## 11. 异常处理

| 验收项 | 操作步骤 | 预期结果 | 是否必须通过 | 风险等级 | 备注 |
|---|---|---|---|---|---|
| 网络异常 | 模拟 API 超时或断网。 | 页面显示错误/重试，不白屏。 | 是 | P1 | 关键页面必须覆盖。 |
| 支付成功但额度未到账 | 模拟订单已支付但额度未更新。 | 后台可追踪并人工修复；用户侧有明确状态。 | 是 | P0 | 高风险。 |
| 生成超时 | 模拟生成长时间无结果。 | 展示处理中/失败/重试，不重复扣费。 | 是 | P0 | 高风险。 |
| 导出空内容 | 对空内容点击导出。 | 阻止导出并提示先生成或编辑内容。 | 是 | P1 | 防止无效交付。 |

## 12. 发布前检查

| 验收项 | 操作步骤 | 预期结果 | 是否必须通过 | 风险等级 | 备注 |
|---|---|---|---|---|---|
| 核心链路冒烟 | 从游客到注册、充值、生成、保存、合稿、导出完整走一遍。 | 全链路完成，无阻塞错误。 | 是 | P0 | 发行前必须人工验收。 |
| 支付风险检查 | 检查支付金额、订单状态、重复回调、额度到账。 | 不出现未支付到账或重复到账。 | 是 | P0 | 发行红线。 |
| 扣费一致性检查 | 检查成功/失败/重试生成的额度变化。 | 扣减规则一致，失败可补偿。 | 是 | P0 | 发行红线。 |
| 合规文案检查 | 检查首页、生成页、导出页是否提示写作辅助和用户自查责任。 | 文案清晰，不承诺代写、伪造数据、规避查重。 | 是 | P0 | 合规红线。 |
| 旧复杂能力不阻塞 | 检查 OnlyOffice、机构端、写手池、全量学术数据是否未作为发行必选。 | 这些能力缺失不阻塞一期发行。 | 是 | P1 | 防止范围膨胀。 |
